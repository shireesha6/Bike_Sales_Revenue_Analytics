# Bike Sales & Revenue Analytics

## 📊 Project Overview
This project analyzes bike sales and revenue data using Microsoft Excel and Power BI. The dashboard provides interactive insights into sales performance, revenue, profit, brands, states, payment modes, and monthly revenue trends.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Power BI
- Data Cleaning
- Data Analysis
- Data Visualization
- Power BI Slicers & Interactive Dashboard

## 📈 Key Analysis
- Brand-wise Profit Analysis
- State-wise Revenue Analysis
- State-wise Profit Margin Analysis
- Payment Mode-wise Revenue Analysis
- Monthly Revenue Trend
- Interactive filtering using State, Brand, Payment Mode, and Month

## 📌 Dashboard
The Power BI dashboard provides an interactive view of bike sales and revenue performance with charts, KPIs, and slicers.

## 📂 Project Files
- `excel project1.xlsx` – Excel dataset and analysis
- `Bike_Sales_Revenue_Analytics_Dashboard.pbix` – Power BI dashboard
- `Screenshot 2026-08-15 173731.png` – Dashboard screenshot

## 🎯 Objective
The objective of this project is to transform raw bike sales data into meaningful business insights using Excel and Power BI.
